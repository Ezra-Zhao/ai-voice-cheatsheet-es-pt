# F5-TTS

- **ES:** Clonación de voz de alta fidelidad con poco audio de referencia; CLI + Gradio.
- **PT:** Clonagem de voz de alta fidelidade com pouco áudio de referência; CLI + Gradio.
- **Paquete:** `f5-tts` (`pip install f5-tts`; también `pip install git+https://github.com/SWivid/F5-TTS.git`)
- **CLI:** `f5-tts_infer-cli --model "F5-TTS" --ref_audio ... --ref_text ... --gen_text ...`
- **Web:** `f5-tts_infer-gradio`

# VoiceStudio

- **ES:** App de escritorio open-source: clonación de voz, doblaje de video, dictado y audiolibros, todo local (alternativa local a ElevenLabs).
- **PT:** App de desktop open-source: clonagem de voz, dublagem de vídeo, ditado e audiolivros, tudo local (alternativa local ao ElevenLabs).
- **Instalación:** paquete de tu plataforma en la página de releases, o desde el código: `git clone https://github.com/debpalash/VoiceStudio.git` → `bun install` → `bun run desktop`
- **Plataformas:** macOS (Apple Silicon), Windows, Linux, Docker
- **Uso:** app → Voice Cloning → asistente de doblaje de video

# Kokoro

- **ES:** TTS compacto de alta calidad con CLI; bueno en CPU.
- **PT:** TTS compacto de alta qualidade com CLI; bom em CPU.
- **Paquete:** `kokoro-tts` (`pip install kokoro-tts`)
- **Archivos requeridos:** `kokoro-v1.0.onnx` + `voices-v1.0.bin` (releases del repo nazdridoy/kokoro-tts, v1.0.0)
- **Comando base:** `kokoro-tts "texto" --output out.mp3`
- **Licencia:** Apache-2.0 (modelo), CLI con su propia licencia (ver repo)
